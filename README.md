# Loopwise 🤖

Learn to code from **absolute zero** to **computer science master's-ready** — free, bite-sized and fun.

- 24 courses from "What is code?" to algorithms, systems, theory and machine learning, plus a full math track
- Real Python and JavaScript running in the browser, checked by automatic tests
- Checkpoint tests to finish every unit, final exams, XP, streaks, levels, achievements, and Pip the robot cheering you on
- Review mode that brings back the questions you missed
- 8 complete courses so far: How Computers Think, Math Refresher, Python Basics, Developer Tools, Python Intermediate, Discrete Math, Data Structures, Algorithms (166 lessons)
- A safe practice terminal for learning the command line hands-on
- Searchable, with a LeetCode-style Practice Arena
- Free accounts (Google or email) save progress across devices

## Quick start
```bash
npm install
npm run dev      # http://localhost:5173
npm test
```
Works without any setup in guest mode. To enable accounts and deploy, follow [docs/DEPLOY.md](docs/DEPLOY.md).
